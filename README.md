# Mini e-commerce electronics

Simple e-commerce style site built with vanilla PHP, JavaScript, and CSS.

## Features
- 3 pages: home, products, auth
- Search, sorting, category filter, price range filter
- AJAX product loading
- Client-side form validation
- PHP + MySQL CRUD

## Setup
1. Create a MySQL database (example: `mini_shop`).
2. Import the schema: [sql/schema.sql](sql/schema.sql)
3. Update DB credentials in [includes/db.php](includes/db.php)
4. Run the project with XAMPP/WAMP and open `index.php`.
